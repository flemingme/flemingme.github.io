adb性能分析

  • 分析启动速度（App Launch Time）

✅ 输出关键指标：

  • Cold Start（冷启动）：TotalTime > 1000ms 需优化
  • Warm Start（热启动）：通常 < 300ms

方法 2：Android Studio Profiler（可视化分析）

  1. 打开 Android Studio → Profiler
  2. 运行你的 Release APK（通过 Run → Profile）
  3. 查看 Startup Timeline（Android 10+ 支持）
    • 显示 Application.onCreate() 到 Activity.onResume() 的完整耗时
    • 可定位初始化瓶颈（如 JS 引擎加载、原生模块注册）

📊 三、监控 CPU 与内存占用

工具 1：Android Studio Profiler（推荐 ✅）

步骤：

  1. 用 USB 连接手机，打开你的 App
  2. 在 Android Studio 中：
    • 点击 View → Tool Windows → Profiler
    • 选择你的进程（如 com.anonymous.XApp）
  3. 实时查看：
    • CPU：线程活动、函数耗时（可录制 Trace）
    • Memory：堆内存大小、对象分配、GC 频率

关键指标：

指标 健康值 风险
冷启动内存 < 100 MB > 150 MB 可能内存泄漏
CPU 峰值 < 70% 持续 100% 导致卡顿
GC 频率 < 1 次/秒 频繁 GC = 内存抖动
