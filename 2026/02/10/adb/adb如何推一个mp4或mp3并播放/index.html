adb如何推一个mp4/mp3并播放

您可以使用 ADB 将一个 MP4 文件推送到设备上，然后使用 ADB Shell 命令来启动视频播放器进行播放。以下是具体步骤：

1. 推送文件到设备

首先，使用 adb push 命令将您本地的 MP4 文件复制到设备的存储空间中。通常推送到 /sdcard/ 或 /storage/emulated/0/ (这是内部存储的根目录) 下比较方便访问。

请务必替换 /path/to/your/local/video.mp4 为您计算机上实际的 MP4 文件路径。

成功后，您会看到类似 ... 100% ... 的传输完成信息。

2. 使用 ADB Shell 启动视频播放

推送完成后，您可以使用 adb shell 结合 am (Activity Manager) 命令来启动一个意图（Intent），该意图会打开默认的视频播放器并播放刚刚推送的视频文件。

命令解释:

  • adb shell: 进入设备的 shell 环境。
  • am start: 启动一个 Activity。
  • -a android.intent.action.VIEW: 指定动作是“查看”。
  • -d "file:///sdcard/video.mp4": 指定要查看的数据 URI，这里是文件路径。请注意路径是 file:/// 开头。
  • -t video/mp4: 指定 MIME 类型为 MP4 视频。

执行此命令后，设备上默认的视频播放器应用应该会被启动，并开始播放位于 /sdcard/video.mp4 的视频。

注意事项

  • 设备连接: 确保您的设备已通过 USB 或无线方式正确连接到电脑，并且 ADB 已识别到设备。
  • 开发者选项与 USB 调试: 设备上必须已启用“开发者选项”和“USB 调试”。
  • 文件路径: 确保推送和播放时使用的路径完全一致。
  • 默认播放器: 此方法依赖于设备上存在能够处理 video/mp4 类型文件的默认播放器。如果系统询问使用哪个应用打开，它会选择一个合适的播放器。
