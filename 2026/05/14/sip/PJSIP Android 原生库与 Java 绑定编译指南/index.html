⚠️ 常见问题

Q1: 编译时报 swig: No such file or directory

解决：安装 SWIG 4.1（推荐）：

Q2: 运行时崩溃 UnsatisfiedLinkError

原因：缺少 libc++_shared.so 或 ABI 不匹配
解决：

  • 确保 jniLibs/arm64-v8a/ 包含两个 .so 文件
  • 检查设备 CPU 架构：adb shell getprop ro.product.cpu.abi

Q3: 如何编译其他 ABI（如 armeabi-v7a）？
