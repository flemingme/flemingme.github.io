二、添加一个新的子模块，并指定分支，默认master

三、修改子模块的代码（如同一般项目的处理）

四、在主项目中更新子模块

注意：如果需要改动子模块的代码才能满足功能的话，要先在子模块的独立项目中修改代码，提交后再到主项目中更新同步

五、仅更新主项目，不自动更新子模块

六、修改需要同步的子模块分支（根据不同项目的需要更新不同的分支）

修改后的.gitmodules如下：
[submodule “mysub”]
path = sub
url = ../sub/.git
branch = develop

  • 删除子仓库目录。
  • git rm –cached <本地路径>
